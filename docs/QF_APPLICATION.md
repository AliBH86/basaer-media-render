**What the project is:**
A non-commercial Instagram page that shares the Quran in Arabic with an English translation, for a general Muslim audience (Sunni and Shia alike), with no advertising, no sales and no sponsored content. It publishes one image post per day (a single ayah) and short video recitations (Reels) four times a week.

**How we use the Quran.Foundation / Quran.com data:**
- Verse text: Uthmani script (`text_uthmani`) for the ayah of the day and for short Reel passages (1 to 8 ayahs).
- Word-level data (`words`, `text_uthmani` per word) to highlight each word in time with the recitation.
- Translation: Saheeh International (resource 20), shown exactly as returned (footnote markers removed only).
- Audio: chapter recitations and their word timing segments (`audio_files?segments=true`) for nine reciters, cut to the selected ayahs.
- Chapter names (`name_arabic`, `name_simple`).

**How the content is protected:**
- The Arabic and English are never typed or edited by hand. Every image and video is compared character by character with a fresh copy from the API before it can be sent for review; any difference blocks the post.
- Every post is reviewed and approved by the owner before publishing.
- Nothing is generated by AI except a short reflection line chosen from a fixed list written and approved by the owner; it is clearly separate from the Quran text.

**Attribution:** every caption carries the line "Text and recitation: Quran.com / Quran Foundation. Translation: Saheeh International." The translation name is also shown on each image.

**Expected volume:** about 1 image post per day and 4 Reels per week. Roughly 20 to 60 API requests per day (verse, words, chapter and audio-timing lookups), plus one chapter audio download per Reel. Requests are made from an automation server (n8n) and from GitHub Actions render jobs. Content is fetched fresh at render time and is not stored long term (well within the one-week caching guidance).

**Why production access:** the project currently uses the public api.quran.com v4 endpoints. We would like to move to the supported Quran.Foundation Content API with proper credentials so that the page keeps working reliably and stays within your terms.
